## 2. Launch Strategy & Prep Checklist

### Step 1: Push Code to GitHub
1. Create a public repository on GitHub named `hr-core-management`.
2. Push your local files (ensure `node_modules` and your `.env` secrets are excluded by `.gitignore`).
3. Place the `README.md` at the root so recruiters see a premium presentation immediately.

### Step 2: Record a 60-Second Walkthrough Video
1. Use a free screen recorder (like Loom, OBS, or Windows Game Bar `Win + Alt + R`).
2. Show the dynamic login flow and the ambient Welcome overlay.
3. Toggle between the **Company Command Center (Admin)** and **HR Operations** dashboards to show the custom widget separation.
4. Open the Settings hub and switch the theme from Premium Dark to Pristine Light to demonstrate the dynamic layout responsiveness.
5. Send a chat message or channel alert to showcase the real-time Socket.IO connection.

### Step 3: Share the Post
1. Upload your recorded 60-second video walkthrough directly to your LinkedIn post (posts with native videos get up to **5x more reach** than text-only posts).
2. Paste the template text from Section 1 above.
3. Pin the GitHub link to the top of your profile page!
