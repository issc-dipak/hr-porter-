The Challenge & Vision

Why HR Core?

Traditional HR Bottlenecks

Most company management dashboards look cluttered, run slow, and fail to provide absolute privacy guidelines between structural roles like general Managers, operational HRs, and employees.

The Modern High-Density Vision

A sleek, glassmorphic workspace using a base HTML font-size scale to compact sizing constraints. Designed to optimize workspace layouts and display crucial operational parameters on one screen.

Decoupled Stack

Technical Stack & Flow

Frontend

Next.js 16 (App Router, TS), TailwindCSS v4, Zustand state management, Framer Motion, TanStack Query for dynamic data cache sync.

Backend API

Node.js & Express REST API, Mongoose schemas, real-time WebSocket room broadcasting using Socket.IO server modules.

Cloud Services

MongoDB Atlas database storage, Cloudinary file uploads, Razorpay payment integrations, and Gemini API for smart comments.

Role Segregation

Customized Portals

Admin Command

Governance dashboard tracking total audit logs, active departments, locked accounts, billing plans, and server health.

HR Operations

Operations control handling onboarding checklist tasks, leave request lists, probation review lists, and recruitment funnel stages.

Employee Workspace

Personal portal showing leaves setup, Pomodoro sprint timers, workplace chat widgets, and Daily Status Report (DSR) logs.

Workspace Collaboration

Workplace Chat & DSR

Socket.IO Messaging Hub

Enables instant Direct Messaging (DMs) and public channels. Implements unread message indicators, sounds muting configurations, online/offline indicators, and typing previews.

Daily Status Reports (DSR)

A digital record card tracking accomplishments, targeted sprints, and blockers. Connects to reviewers for ratings and automated feedback using backend integrations.

Aesthetic Polish

Premium High-Density Layout

HTML Base Scaling

Roots font scale set to `13.5px` to reduce all rem-based sizes, paddings, and borders proportionally.

Narrower Sidebar

Sidebar width compacted to 208px, with font sizes at 11px and icon boundaries set to w-4 h-4.

Sleeker Controls

All button heights set to 36px and forms modified to 10px rounded boundaries for premium finish.

Ready for Launch
